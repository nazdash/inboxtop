# Project guidance

Read [PRINCINPLES.md](PRINCINPLES.md) before planning or implementing any new
functionality or change. It is the main product reference; check decisions against
its principles in order, with earlier principles taking priority when they conflict.

Follow [AGENTS.md](AGENTS.md) for repository instructions. For interface work, also
read [UI-PRINCIPLES.md](UI-PRINCIPLES.md): it describes how the interface
implements the product principles, rather than replacing them.

For installation or account setup, follow [the agent installation runbook](docs/AGENT-SETUP.md).
Use its ordered steps, machine-readable checks and credential handoff. Report
installed, configured and connection-tested as separate outcomes.
